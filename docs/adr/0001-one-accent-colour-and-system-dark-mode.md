# One accent colour, and dark mode that follows the system

The app stays minimal: a neutral grey palette plus exactly one accent colour (lime family), used only for primary actions, Follow-along progress and selected options. We considered giving Difficulty levels and Blocks their own colours and rejected it for now, since every extra colour competes with the one that says "tap here". A new colour needs a new decision, not just a new token.

Dark mode follows the system theme by default, with a manual System / Light / Dark override remembered per device. Follow-along uses the same theme as the rest of the app rather than a forced dark "workout mode", so the app looks the same wherever the user is in it. Exercise pictures keep their light tiles in dark mode instead of being inverted or recut, because filters distort the figures and the 144 GIFs and Key poses have opaque white backgrounds.

One exception: the amber "switch sides" badge in Follow-along. It is a warning that has to catch the eye mid-Set, and lime already means "tap here", so warnings keep amber. Rest progress, which used to be blue, is grey.
