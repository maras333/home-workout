# Decide whether a browsable Exercise library page is in the MVP

> Archived: this ticket now lives in GitHub issue [#10](https://github.com/maras333/home-workout/issues/10).

Type: grilling
Status: resolved
Map: [Home Workout MVP](../map.md)

## Question

Does the MVP have a page for browsing Exercises outside a Workout (GIF, steps, "Trains: …", Equipment, Difficulty)? If yes:
- how it's reached
- what filters it offers

The Exercise detail dialog already exists: [Define the Workout preview screen](08-define-workout-preview.md) decided it, built for reuse. A library page would open the same dialog.

## Answer

**Not in the MVP; ruled out of scope.** The MVP is the core flow: Workout Request → Workout preview → Follow-along → Favourites. You only ever meet Exercises inside a Workout, and the Exercise detail dialog from [Define the Workout preview screen](08-define-workout-preview.md) already answers "what is this Exercise?". A page for browsing every Exercise, with filters and a header link, can come back as a later effort.
